# AcessaCidade

## Resumo
> **FIAP · 4ESPS · 2º Global Solution 2026 · CitizenTech**
>
> Plataforma web para o cidadão registrar barreiras de acessibilidade nas calçadas (buracos, pisos
> quebrados, rampas irregulares, obstáculos), com triagem automática inicial da foto.

## Project-Based Maker Lab

Componente físico do AcessaCidade: 
- **Laser**: Placa de sinalização acessível para ponto de ônibus, com área reservada para o QR Code que leva o cidadão à tela de registro do AcessaCidade para reportar problemas de acessibilidade naquele ponto.
- **3D**: Botoeira para travessia de pedestres remodelada para facilitar o uso por idosos e pessoas com deficiência visual. O novo modelo conta com dois botões: um de tamanho ampliado, proporcionando maior acessibilidade para a população em geral, e outro com identificação em alto contraste, que emite um sinal sonoro quando a travessia é liberada.
